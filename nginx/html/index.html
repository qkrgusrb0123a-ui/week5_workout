WEEK 5 · CAPSTONE

업스케일 랩(Upscale Lab)

누적 조회수 불러오는 중

프로젝트 소개

저해상도 이미지를 AI 업스케일을 통해 고해상도로 변환하고 자동으로 배경화면까지 적용해주는 프로그램입니다.

주요 기능

- AI 이미지 업스케일링
- 화면 비율 자동 감지
- 화면 비율 맞춤 이미지 편집
- 이미지 갤러리
- 이미지 API 지원
- 이미지 다운로드
- Windows 배경화면 적용
- 클라우드 데이터 동기화

사용 기술

- Web Frontend
- Flutter / Dart
- Backend API
- Cloud Database
- Docker
- nginx
- Flask

팀 소개

전찬울: AI 업스케일링 기술 및 배경화면 자동 적용 구현
남인호: 클라이언트 구성 및 UI 제작
박현규: 백엔드 구성 및 데이터 관리

API 연결 확인

페이지를 열거나 새로고침하면 조회수가 증가합니다.
